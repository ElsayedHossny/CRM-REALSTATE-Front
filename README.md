# 🏠 Real Estate CRM — Property Management System

**Real Estate CRM** is a web-based Customer Relationship Management system developed as part of the **NTI (National Telecommunication Institute) training program**.

The project was designed to provide a complete platform for managing real estate properties, customers, and business operations through a modern **website and administrative dashboard**.

I worked on the project as the **Team Leader**, collaborating with a team of **5 developers** throughout the development process.

---

## 📸 Project Overview

The system is designed for real estate businesses to manage their properties and customer relationships through a centralized platform.

The project consists of two main parts:

### 🌐 Website

A user-facing platform where users can:

* Browse available properties
* View property details
* Explore different property categories
* Search for suitable properties
* View property information in an organized interface

### 📊 Admin Dashboard

A management dashboard designed to help administrators manage the platform and its data.

The dashboard provides functionality for:

* Managing properties
* Managing customers
* Managing property-related data
* Monitoring and organizing business information
* Managing the system through a centralized interface
